# WarpTools coordinate export

Save the traced skeleton in napari, then run this in the filament-tracer environment:

```bash
python scripts/export_warp.py \
  --skeleton manual.ftskeleton.json \
  --output warp_coordinates.star \
  --inter-box-distance 100 \
  --coords-angpix 10 \
  --tomo-name TS_01
```

The numbers are examples. `--inter-box-distance` is spacing along the filament
in angstroms. `--coords-angpix` defines the output coordinate units; it need not
equal the extraction pixel size. The exporter uses the skeleton's saved voxel
spacing (including unequal Z/Y/X spacing) to convert positions into these units.
Use exactly the same value for WarpTools `--coords_angpix` below.

`--tomo-name` must exactly match Warp's tilt-series identifier, as found in
`rlnMicrographName` in a Warp-generated picking STAR. It is not necessarily the
reconstructed MRC filename. Names are preserved verbatim; no suffix is guessed.

The STAR contains `rlnMicrographName`, uncentered `rlnCoordinateX/Y/Z`,
`rlnHelicalTubeID`, and `rlnHelicalTrackLengthAngst`. It contains coordinates,
not extracted images or CTF metadata. Existing files are never overwritten.
Sampling and validation follow the [RELION exporter](relion_export.md).

## Coordinate frame

Trace a Warp reconstruction made using the alignment that will be used for
extraction. XYZ = reverse(saved ZYX * saved voxel spacing) / coords_angpix.
There is no centering, one-pixel shift, axis flip, or normalization.

For an axis-aligned crop, supply its origin in the full Warp reconstruction:
`--offset-xyz-angst 100 200 300` adds that XYZ translation in angstroms before
conversion to pixels. Rotated/flipped volumes require explicit registration
outside this exporter. MRC origin metadata is not inferred. Negative transformed
positions are rejected; the exporter cannot check the full Warp volume's bounds
or per-tilt visibility. Verify a small extraction first, especially Z and cropping.

## Extract with WarpTools and refine in RELION 5

Run in the Warp environment/project, using its updated alignment and CTF metadata:

```bash
WarpTools ts_export_particles \
  --settings warp_tiltseries.settings \
  --input_star warp_coordinates.star \
  --coords_angpix 10 \
  --output_star relion/filaments.star \
  --output_angpix 4 \
  --box 96 \
  --diameter 200 \
  --2d
```

Choose extraction pixel size, even box size (pixels), and diameter (angstroms)
for your sample. Do **not** use `--normalized_coords` with this export.
Check Warp's matched particle counts and inspect extracted particles before a
full run. Preserve the original STAR and skeleton as filament provenance;
metadata passthrough depends on the installed WarpTools version.

Use `relion/filaments_optimisation_set.star` in RELION 5's `relion --tomo`
refinement interface. Warp performs extraction with its geometry. This does not
provide a full native RELION tilt-series import for re-extraction or polishing.
Euler angles and filament polarity are not generated by this exporter.
